# LiFE RPG — Геймификатор жизни

Превратите свою жизнь в RPG с помощью AI! Записывайте действия, получайте XP и золото, выполняйте квесты, достигайте целей.

## 🚀 Быстрый старт

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Открыть в браузере
# http://localhost:5173
```

## 📦 Продакшн-сборка

```bash
npm run build
```

Результат в папке `dist/` — статический сайт, который можно задеплоить куда угодно.

## ⚙️ Настройка

1. Откройте приложение
2. Перейдите в **⚙ Настройки**
3. Вставьте Gemini API ключ (получить: https://aistudio.google.com/apikey)
4. Готово!

## 🎮 Основные функции

### 📊 Обзор (Dashboard)
- Общий уровень и прогресс
- Тепловая карта активности (90 дней)
- Streak counter — серия дней подряд
- Прогресс по категориям с уровнями
- Список артефактов

### ⚡ Действия (Action Logger)
- Записывайте действия в свободной форме
- AI автоматически определяет категорию и начисляет XP + золото
- Быстрые чипы для повторения частых действий
- История всех записей
- Лог добавок (автоматически извлекается из текста)

### 🎯 Цели (Goals)
- Долгосрочные цели с AI-планировщиком
- AI генерирует 2-3 варианта плана
- Можно уточнять и дорабатывать планы
- Выполнение шагов даёт XP и золото
- Прогресс-бары для каждой цели

### 🌱 Зёрна (Seeds)
- Система исследования затруднений
- AI предлагает варианты подходов
- Эксперименты с обратной связью
- Успешные эксперименты превращаются в **Артефакты**

### 💭 Советник (Brainstorm)
- AI-диалог с контекстом ваших данных
- Видит статы, историю, активные цели
- Предлагает 0-3 целесообразных действия
- Живой диалог — можно спорить и уточнять

### 🛒 Магазин желаний (NEW!)
- **Две валюты**: XP (для роста) и золото (для магазина)
- Золото зарабатывается за действия (1 🪙 за каждые 5 XP)
- Два тира предметов:
  - Маленькие радости (10-20 🪙) — кофе, сериал, вкусняшка
  - Большие хотелки (100+ 🪙) — день без дел, покупка, выходной
- Можно добавлять свои предметы
- Покупка только когда реально хочешь — награда за дисциплину

### ⚙ Настройки
- API ключ и модель
- Веса категорий (влияют на множитель XP)
- Достижения (12 штук)
- Статистика
- Экспорт/импорт данных (JSON)

## 🎯 Система наград

### XP (Опыт)
- Начисляется за каждое действие
- Определяет уровень в категории и общий уровень
- Не тратится, только растёт
- Формула: `base_xp × category_weight × contribution_factor`

### Золото 🪙 (NEW!)
- Начисляется вместе с XP (1 🪙 за каждые 5 XP)
- Тратится в магазине желаний
- Бонус за скорость: быстрые действия дают ×1.5 золота
- Мотивирует не откладывать

### Уровни
- Каждая категория имеет свой уровень
- Общий уровень рассчитывается из суммы XP
- Прогрессивная шкала: каждый уровень требует на 15% больше XP

### Достижения
- 12 ачивок за различные достижения
- Автоматически разблокируются
- Примеры: "Первый шаг", "Неделя силы", "Достигатор"

## 🧠 AI-функции

Все AI-функции используют Gemini API:

1. **Game Master** — парсит свободный текст в структурированные квесты
2. **Goal Planner** — разбивает цели на конкретные шаги
3. **Brainstorm** — предлагает целесообразные действия
4. **Seed Quest** — исследует затруднения через эксперименты
5. **Seed Verdict** — оценивает результаты экспериментов

## 💾 Хранение данных

- Все данные хранятся в `localStorage` браузера
- Экспорт/импорт через JSON-файлы
- Для синхронизации между устройствами используйте экспорт-импорт
